# my-blog

Личный блог [javharbek.uz](https://javharbek.uz) на трёх языках: русский, o‘zbekcha, English.

Статический сайт без зависимостей: HTML, CSS и немного JavaScript для интерактивных графиков. Готовые страницы лежат в репозитории, GitHub Pages ничего не собирает.

## Структура

```
index.html                 выбор языка (по языку браузера, затем по сохранённому выбору)
ru/ en/ uz/                главная каждого языка: hero, записи с поиском и фильтром, разделы, формула недели, исследования
ru/about/                  страница «Обо мне» (аналогично en/, uz/)
ru/<slug>/index.html       запись (аналогично en/, uz/)
ru/materials/              раздел «Материалы»: список шпаргалок и справочников (аналогично en/, uz/)
ru/materials/<slug>/       материал целиком, например ml-formulas — шпаргалка формул нейросетей
assets/css/site.css        единый стиль: токены светлой и тёмной темы, компоненты
assets/js/site.js          тема, память языка, поиск и фильтр, прогресс чтения
assets/js/sigmoid.js       интерактивные графики записи о сигмоиде
assets/js/materials.js     страница материала: формулы KaTeX, фильтр по группам, «раскрыть всё»
assets/img/javharbek.png   фото автора
tools/build.py             генератор страниц; тексты интерфейса, разделы, список записей, «Обо мне»
tools/content_sigmoid.py   тексты статьи о сигмоиде
tools/content_formulas.py  тексты шпаргалки формул (три языка)
.github/workflows/pages.yml деплой на GitHub Pages при пуше в main
```

## Новая запись

Добавьте запись в список `POSTS` в `tools/build.py`, тексты статьи положите в `tools/content_<slug>.py` по образцу `content_sigmoid.py`, добавьте функцию рендера, затем:

```
python3 tools/build.py
```

и закоммитьте результат вместе со скриптом.

## Новый материал

Материал — долгоживущая справочная страница в разделе «Материалы». Положите тексты в `tools/content_<slug>.py` по образцу `content_formulas.py`, добавьте его в список `MATERIALS` и функцию рендера в `tools/build.py`. Чтобы о материале узнали с главной, добавьте в `POSTS` новость с относительным `url` (`materials/<slug>/`): такая строка показывает «Открыть материал →».

## Дизайн

Текущий дизайн (`main`) собран по макету «Блог учёного-инженера»: Manrope для текста, STIX Two Text для формул, светлая и тёмная тема, переключатель RU / EN / UZ. Первая, минималистичная версия сохранена в ветке `design-v1-minimal`.

## Локально

```
python3 -m http.server 8000
```

и откройте http://localhost:8000.
