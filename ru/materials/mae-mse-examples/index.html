Как читать формулы

Обе метрики отвечают на вопрос «насколько модель ошибается?». Есть $n$ объектов; для каждого известен правильный ответ $y_i$ и прогноз модели $\hat y_i$ (читается «игрек с крышкой»). Разница $e_i = y_i - \hat y_i$ — ошибка на объекте $i$.

$y_i$
правильный ответ (истина) для объекта $i$
$\hat y_i$
прогноз модели для объекта $i$
$e_i = y_i - \hat y_i$
ошибка: плюс — модель занизила, минус — завысила
$n$
число объектов
$\sum_{i=1}^{n}$
сумма по всем объектам от $1$ до $n$

Рецепт из четырёх шагов

  1. Выпишите пары $(y_i,\ \hat y_i)$ и посчитайте ошибки $e_i = y_i - \hat y_i$.
  2. Для MAE возьмите модуль каждой ошибки $|e_i|$, для MSE — квадрат $e_i^2$.
  3. Сложите все модули (или все квадраты).
  4. Разделите сумму на $n$ — это и есть MAE (или MSE).
Как читать ответ

MAE — средний размер промаха в тех же единицах, что и $y$: «в среднем ошибаемся на 0,83». MSE — средний квадрат промаха, в единицах «в квадрате»; она сильнее реагирует на большие ошибки. Обе метрики: чем меньше, тем лучше, ноль — идеал.

Пример с доски

Начнём с примера, разобранного на уроке: три объекта, три прогноза. Каждый шаг ниже — ровно то, что написано на доске, только подробнее.

Пример 1★☆☆

Пример с доски

$y = (3;\ 5;\ 8)$,   $\hat y = (2{,}5;\ 5;\ 10)$. Найдите MAE и MSE.

Разбор и ответ

1. Ошибка каждого объекта $e_i = y_i - \hat y_i$ и её модуль:

$$\begin{aligned}\lvert e_{1}\rvert &= \lvert 3-2{,}5\rvert = \lvert 0{,}5\rvert = 0{,}5\\\lvert e_{2}\rvert &= \lvert 5-5\rvert = \lvert 0\rvert = 0\\\lvert e_{3}\rvert &= \lvert 8-10\rvert = \lvert -2\rvert = 2\end{aligned}$$

2. Сумма модулей:

$$\sum_{i=1}^{3}\lvert e_i\rvert = 0{,}5 + 0 + 2 = 2{,}5$$

3. MAE — делим сумму на $n = 3$:

$$\mathrm{MAE} = \frac{1}{3}\cdot 2{,}5 = \frac{2{,}5}{3} \approx 0{,}83$$

4. Квадрат каждой ошибки:

$$\begin{aligned}e_{1}^2 &= (3-2{,}5)^2 = 0{,}5^2 = 0{,}25\\e_{2}^2 &= (5-5)^2 = 0^2 = 0\\e_{3}^2 &= (8-10)^2 = (-2)^2 = 4\end{aligned}$$

5. Сумма квадратов:

$$\sum_{i=1}^{3}e_i^2 = 0{,}25 + 0 + 4 = 4{,}25$$

6. MSE — делим сумму на $n = 3$:

$$\mathrm{MSE} = \frac{1}{3}\cdot 4{,}25 = \frac{4{,}25}{3} \approx 1{,}42$$

$$\begin{aligned}1 + |6-\hat y_2| &= 2\\|6-\hat y_2| &= 1\end{aligned}$$

3. Модуль равен 1, значит выражение под ним равно $1$ или $-1$:

$$\begin{aligned}6-\hat y_2 = 1 &\Rightarrow \hat y_2 = 5\\6-\hat y_2 = -1 &\Rightarrow \hat y_2 = 7\end{aligned}$$

4. Проверим MSE для обоих ответов — она одна и та же:

$$\begin{aligned}\hat y_2 = 5:\quad \mathrm{MSE} = \frac{1 + 1}{2} = 1\\\hat y_2 = 7:\quad \mathrm{MSE} = \frac{1 + 1}{2} = 1\end{aligned}$$

Ответ: $\hat y_2 = 5$ или $\hat y_2 = 7$; MSE = 1.

Что видно из примера

Задачу «наоборот» решают тем же рецептом: записать формулу, подставить известное и найти неизвестное. Модуль даёт два ответа — прогноз мог ошибиться вверх или вниз.

Частые ошибки

  • Забыли модуль. Ошибки −2 и +2 «сократились» в ноль — а модель ошибалась оба раза (примеры 5 и 15).
  • Возвели в квадрат минус неправильно. $(-3)^2 = 9$, а не $-9$: квадрат любого числа не отрицателен (пример 8).
  • Разделили не на то $n$. Делим на число объектов, а не на число ненулевых ошибок (пример 7).
  • Усреднили, а потом возвели в квадрат. MSE — среднее квадратов, а не квадрат среднего: для ошибок −5 и +5 MSE = 25, а «квадрат средней ошибки» был бы 0.
  • Сравнили MAE с MSE «по величине». У них разные единицы: при ошибках меньше 1 MSE меньше MAE, при больших — больше (примеры 6 и 3).
  • Перепутали порядок вычитания. Не страшно: $|y - \hat y| = |\hat y - y|$ и $(y - \hat y)^2 = (\hat y - y)^2$. Но ошибку со знаком принято считать как $y_i - \hat y_i$.

Проверь себя

1. $y = (2;\ 4)$, $\hat y = (3;\ 1)$. Чему равна MAE?
Ошибки $-1$ и $3$, модули $1$ и $3$, сумма $4$, делим на $n = 2$: MAE = 2.
2. Для тех же чисел чему равна MSE?
Квадраты ошибок $1$ и $9$, сумма $10$, делим на $2$: MSE = 5.
3. Все ошибки увеличили втрое. Во сколько раз вырастет MSE?
Каждый квадрат растёт в $3^2 = 9$ раз, значит и их среднее — тоже в 9 раз (MAE выросла бы втрое).
4. Какое одно число $c$ минимизирует MAE для данных $(1;\ 2;\ 10)$?
MAE минимизирует медиана, а медиана набора $1, 2, 10$ — это $2$. Среднее $\frac{13}{3}$ минимизировало бы MSE.
5. Ошибки модели: $0{,}1;\ 0{,}2;\ 0{,}3$. Что больше?
Все ошибки меньше 1, их квадраты ещё меньше: MAE = 0,2, MSE ≈ 0,0467.
